# gifs/

Empty on purpose: this repo ships no GIFs. Put yours in a library folder next to
the repo (`../pixelpane-library/gifs/`, deployed by `tools/deploy.sh`) or
upload them on the control page. See [docs/GIFS.md](../docs/GIFS.md) for where
to find GIFs, how to make them, and the naming and theme folders.
