# Seasonal GIFs

GIFs in `themes/<theme>/` only play while that theme is active (see
`pixelpane/seasons.py`), and then make up about a third of GIF picks. Drop
32x32 GIFs in (use `tools/ingest-gif.sh`), commit, and deploy. The web page
can also upload straight to a theme; those uploads live only on the Pi.

Themes: autumn, winter, spring, summer, halloween, thanksgiving, christmas,
new_year, valentines, st_patricks, july4, birthday.
